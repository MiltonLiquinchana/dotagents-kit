# Ejemplos de `project.md`

Los archivos `ejemplos/<carpeta del stack>/project.md` están completados para un proyecto ficticio de
pedidos, uno por stack. Úsalos como referencia para `.agents/rules/project.md` en tu proyecto: el generador crea ese archivo
una vez desde la plantilla, con secciones «(por completar)», y no lo vuelve a sobrescribir.

Los nombres de servicios, rutas y servidores son inventados. Escribe en el tuyo los datos reales de
tu proyecto, sin credenciales ni valores secretos.
